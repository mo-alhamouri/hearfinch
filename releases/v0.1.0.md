First public version of Hearfinch: press listen and find out what's playing.

### Website
- Identifies songs, movies, TV shows, podcasts and ads from a short clip
- Result cards with title info, cast, and where to watch or listen — never the scene or episode
- Shareable result links, plus history and settings saved in your browser
- Works on desktop and mobile; demo mode with sample results until the API is connected

### API (Cloudflare Worker)
- Songs and ads by audio fingerprint (ACRCloud)
- Movies and shows by matching dialogue against a subtitle index (Cloudflare D1), with details and where-to-watch from TMDB
- Clearly labelled AI best guess when nothing matches
- Website-only access, per-visitor rate limiting and an optional bot check

### Not yet
- Podcast matching
- Real identification needs the API keys and dialogue index set up (see `worker/README.md`)
